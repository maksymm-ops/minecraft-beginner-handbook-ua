# Minecraft: Відкривай можливості

Неофіційний інтерактивний путівник Minecraft Java Edition для новачків українською мовою.

Книга пояснює не лише **що** робить предмет, а й **навіщо він потрібен**: як почати користуватися ковадлом, зачаруваннями, жителями, Незером, редстоуном та іншими можливостями гри.

## Відкрити локально

Відкрий `index.html` у сучасному браузері. Сайт не потребує встановлення програм чи сервера.

## Що вже є

- обкладинка та зміст із запам’ятовуванням місця читання;
- шість розділів і 24 картки;
- адаптація для телефона, планшета й комп’ютера;
- короткі пояснення, схеми, завдання «Спробуй за 5 хвилин» і пов’язані відкриття.

## Технології

Статичний HTML, CSS і JavaScript. Дані не надсилаються на сервер: прогрес читання, якщо браузер це дозволяє, зберігається лише локально у браузері.

## Статус

Проєкт у розробці. Зміст і дизайн будуть поступово доповнюватися.
